## Steps
1. Add `BrandWordmark` widget (lib/core/theme/brand_wordmark.dart): one typography for NShoptor (bold, tight letter spacing, primary color, 'N' accent).
2. Use it in the splash, the Settings about row and the paywall header.
3. Splash follows the theme: surface color from the active ColorScheme; Android native splash dark in values-night and values-night-v31.
4. Splash stays at least 1.5 s so the name and slogan are readable.
