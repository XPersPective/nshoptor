## Steps
1. Add palettes (forest default, ocean, sunset, lavender) and a black (AMOLED) dark style to AppTheme.
2. Store the palette and dark style in AppThemeModeController (keys app.palette, app.darkStyle); default system mode, forest, black dark.
3. Settings: palette chips and dark style switch under the existing theme setting.
4. Tests: each palette builds light and dark ThemeData; black style uses pure black surface.
