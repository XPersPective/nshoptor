# PB-038 — Keşfet sekmesi + Hakkında/Lisanslar/Paylaş + sürüm dizesi

## Status

PLANNED (PB-037 ile paralel yürütülebilir; EntitlementSource hazır olmalı)

## Objective

Şablonun ortak yüzeylerini kur (standart §3.3–3.6): Keşfet sekmesi,
Hakkında (açık kaynak BELİRGİN), Lisanslar, Paylaş, Puan ver; sürüm
dizesinden "Aşama 4" jargonunu kaldır (C-035).

## Somut değişiklikler

1. **HomeShell 5 sekme:** Ana Sayfa, Listeler, Geçmiş, **Keşfet**, Ayarlar
   ( bottom bar 5 öğeye çıkar; banner yine altında, PB-037).
2. **Keşfet:** napp_core `OtherAppsPage`; veri `apps.json` (URL
   env_config'den — Crazy Penguin'in public reposu; bilinmiyorsa UNKNOWN +
   geçici test URL'si önbellek/yedekli davranışı doğrulamak için).
   Önbellek 24 saat; çevrimdışı → önbellek → gömülü kopya. Kendi paket
   adı listeden gizlenir. Bozuk kayıt atlanır (C-002 doğrulama).
3. **Hakkında (AboutPage):** logo + ad + sürüm + slogan; belirgin "Açık
   kaynak" bölümü (GPL-3.0, bir cümlede anlamı, GitHub kaynak bağlantısı,
   katkı/issue bağlantısı); gizlilik tek cümle (VERİ=YEREL + reklam SDK
   gerçeği) + politika bağlantısı; iletişim (e-posta dart-define);
   Lisanslar bağlantısı. Sürüm dizesi: `aboutVersion` ARB'lerinden
   "(Aşama 4)" kaldır → pubspec sürümünden türe ("1.0.0").
4. **Lisanslar:** `showLicensePage` sarmalayan napp LicensesPage +
   `THIRD_PARTY_LICENSES.md` (her paket: ad, kullanım, lisans) +
   uygulamanın GPL-3.0'ı en üstte.
5. **Paylaş/Puan:** ShareService (share_plus, uygulama dili + Play
   bağlantısı); ReviewService/in_app_review (RatePromptPolicy: yalnızca
   olumlu an, seyrek; Ayarlar'da "Puan ver" satırı).
6. apps.json kaydı: NShoptor için kayıt içeriği (id, paket adı, ikon URL,
   ad/açıklama tr+en, order) hazırlanır ve Crazy Penguin'in apps.json
   reposuna iletilmek üzere `docs/store/apps-json-entry.md` olarak yazılır
   (repo adresi bilinmediğinden push edilemez; Decision Boundary).

## Dependencies

## Acceptance Criteria

- Keşfet: apps.json çekilir, kendisi gizlenir, çevrimdışıtested (uçak
  modu emülatör), bozuk JSON crash YOK.
- Hakkında: açık kaynak bölümü ilk bakışta görünür; "Aşama" geçmez —
  grep kanıtı: `lib/` altında "Aşama" yalnız CHANGELOG'da olabilir.
- Lisanslar ekranı açılır; THIRD_PARTY_LICENSES.md tüm pubspec
  bağımlılıklarını kapsar (script/betik ile üretilen liste elle doğrulanır).
- Paylaş: play bağlantısı + yerelleştirilmiş metin (emülatör chooser).
- Puan: Ayarlar satırı mağaza sayfasını açar; istem politikası testli.
- analyze 0 + test yeşil + release emülatör walkthrough.
