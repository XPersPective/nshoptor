# PB-033 — Kapanmış depoların UI bağlantıları

(Eski planın T30'a devrettiği UI işleri; T16/T17/T19/T23/T25/T27 artıkları)

## Status

PLANNED

## Objective

Mantığı ve testleri tamamlanmış fakat ekrana bağlanmamış yeteneklerin UI
bağlantılarını yap:

1. Ses girişi: ürün formuna mikrofon düğmesi + ses önizleme sayfası
   (VoiceCommandParser çıktısı ItemFormSheet initial-value'larına) — T23 artığı
2. Raf etiketi: fotoğraf kırpma/döndürme + etiket uygulama UI'sı
   (ShelfPriceExtractor adayları kullanıcıya seçtirir) — T25 artığı
3. Fiş inceleme ekranı: ReceiptReviewController'ı tam ekrana bağla
   (kabul/yoksay/bağla/ayır/birleştir, fark gösterimi) — T27 artığı
4. Şablonlar: ana ekrana "önceki alışverişten plan" şablon kartı — T19 artığı
5. Fiyat geçmişi erişimi: sonuç/geçmiş ekranından ürün fiyat geçmişine
   geçiş — T17 artığı

## Acceptance Criteria

- Ürün formunda mikrofon düğmesi ses önizleme sayfasını açar; parser çıktısı
  form alanlarına dolar, kullanıcı düzenleyip onaylar
- Raf etiketi akışında fotoğraf kırpılabilir, fiyat adayları listelenir,
  kullanıcı seçimi forma yazılır
- Fiş inceleme ekranı receipt akışına bağlı; onay öncesi DB yazımı yok
- Ana ekranda şablon kartı createPlanFromActuals çağırır
- Fiyat geçmişi ekranına en az bir akıştan erişim var
- `flutter analyze` 0 issue; ilgili feature testleri geçer
