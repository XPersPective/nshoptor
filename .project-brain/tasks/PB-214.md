## Objective
Build durable cross-platform background processing (`Android + iOS`) so queued receipts continue parsing even when the user navigates away or closes/backgrounds the app, fire a notification when ready (*"Fiş hazır, listeye aktarmak ister misin?"*) that routes directly to review/conversion, add the `"Fişlerim (N)"` tab with unconverted count badge, `(store + date + time)` duplicate warning, `"Listeye Çevir"`, always-available delete, and attached receipt photo viewer at the bottom of the resulting shopping list.

## Steps
1. Create `lib/features/receipts/receipt_queue_service.dart`:
   - Sequentially processes `queued` receipts in Drift using Server Vision AI primary (offline fallback when offline/disabled), checks `(store + date + time)` duplicate detector (`receipt_dedup.dart`), stores candidate lines + metadata, marks `ready` or `duplicate` (with `duplicateOfListId`) or `error`, and calls `LocalNotificationsScheduler.showReceiptDraftReady(...)` (`receipt-draft:<id>`).
   - Supports `reconcileAndDrain()` on boot and `AppLifecycleState.resumed` (resetting stale interrupted `processing` rows to `queued`), plus `@pragma('vm:entry-point')` background worker entrypoint `receiptQueueBackgroundMain()`.
2. Add thin native background wakeup hooks (`MethodChannel('nshoptor/background_queue')`):
   - Android (`MainActivity.kt` + `ReceiptQueueWorker.kt` using `androidx.work:work-runtime-ktx` with `NetworkType.CONNECTED` and `AndroidManifest.xml` / `app/build.gradle.kts`): if main engine is active, wake its queue; if process restarted headless, launch single-engine background entrypoint cleanly without SQLite locks.
   - iOS (`AppDelegate.swift` + `Info.plist` `BGTaskSchedulerPermittedIdentifiers` / `UIBackgroundModes: processing`): use `UIApplication.beginBackgroundTask` for immediate background completion plus `BGProcessingTaskRequest` (`com.crazypenguin.nshoptor.receipt-queue`) when suspended.
3. Update `LocalNotificationsScheduler` and `HomeShell` (`home_screen.dart`) to handle `receipt-draft:<id>` notification payloads cleanly, navigating straight to `Fişlerim` / `ReceiptReviewScreen`.
4. Add 4th tab `"Fişlerim (N)"` to `ListsScreen`:
   - Reactive badge `(N)` showing unconverted receipts count.
   - Displays status badges (`Sırada`, `Hazırlanıyor`, `Listeye çevirmeye hazır`, `Bu fiş daha önce girilmiş olabilir`, `Hata`), `"Listeye Çevir"` CTA (with duplicate prompt *"zaten bu fiş girildi"* -> Add anyway / Delete when duplicate), `"Tekrar dene"`, and Delete anytime (updating `(N)` immediately and cleaning up orphaned JPEG files).
5. Ensure conversion (`ReceiptReviewScreen` -> save) sets `queueState = 'converted'`, `convertedAt`, links `listId`, retains receipt photo(s) at the bottom of `ListDetailScreen` (`_ReceiptsSection`) with an interactive full-screen photo preview modal, and keeps `C-004` confirmation mandatory.
6. Add comprehensive widget + queue + dedup + notification routing tests cleanly passing in VM.
