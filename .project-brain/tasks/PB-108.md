## Objective
User: "düşük plandan yüksek plana yükseltebilir ve düşük planın o anki ödemesi düşmesi lazım... ödeme yapmadan satın almayı tamamladıysa onu göstermiyor." Upgrade replaces the current subscription with proration; the shown plan must match Play ownership without reloading the page.

## Steps
1. Read subscription_service.dart: buy, restore, applyOwned, load and _refreshGeneration; list every path that changes the tier.
2. When the user owns Pro and buys Max, pass the owned purchase as the old purchase with a prorated replacement mode (in_app_purchase_android ChangeSubscriptionParam). Same product: no purchase.
3. On the purchase stream: purchased or restored -> applyOwned and notify; pending -> show pending; error or canceled -> keep the previous tier and call queryPurchases.
4. Refresh ownership when the app resumes (WidgetsBindingObserver) and when the paywall opens.
5. Fake-IAP tests: upgrade passes the old purchase; canceled purchase keeps the tier; purchased event updates the tier without reopening the page.
