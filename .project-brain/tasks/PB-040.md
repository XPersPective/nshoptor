# PB-040 — Fiş OCR eşleştirmesinin gerçekçi doğrulaması

## Status

PLANNED (PB-036 sonrası)

## Objective

Kullanıcının beklentisi: fiş fotoğrafı → cihaz içi (ücretsiz) OCR →
"domates" satırındaki rakamın plandaki "domates" ürününe doğru yere
yazılması; KDV/vergi satırlarının tanınması. Harici ücretli servis YASAK
(C-005). Mevcut altyapı (MlKitTextSource + ReceiptParser + ReceiptMatcher
+ ReceiptReviewScreen) güçlendirilir ve GERÇEKÇİ girdiyle kanıtlanır.

## Somut değişiklikler

1. Test corpus: internetten 3+ gerçekçi Türk market fişi METNİ (market
   adı, kategori satırları, "DOMATES KG 24,90", toplam, KDV satırları,
   kart/nakit dengesi) `test/fixtures/receipts/*.txt` olarak toplanır
   (metin düzeyi; görsel telifine dikkat — yalnızca sahte/anonimleştirilmiş
   veya serbest örnekler; gerekiyorsa sentetik fiş üretilir).
2. ReceiptParser: KDV/toplam/ödeme satırları sınıflandırması; kategori
   başlığı satırlarının ürün sanılmaması; ondalık virgül/nokta toleransı.
3. ReceiptMatcher güçlendirme: normalize (Türkçe küçük harf, sesli
   harf normalizasyonu) + Levenshtein/benzerlik eşiğiyle öneri
   ("domates"↔"DOMATESE KG"); eşleşme güven düzeyi review ekranında
   kullanıcıya net gösterilir (yüksek/düşük); öneri yalnızca ÖNERİDIR,
   kullanıcı onayı zorunlu (C-003 değişmez).
4. Otomatik öneri bağlama: review ekranında yüksek güvenli eşleşmeler
   önceden işaretli gelir (kullanıcı tek dokunuşla onaylar) — mevcut
   "yalnız manuel link" davranışının iyileştirilmesi; kullanıcı isteği
   ("otomatik ... tanıyıp yazabilecek").
5. Emülatör doğrulaması: sentetik ya da açık lisanslı bir fiş GÖRSELİ
   galeriye atılır → pickImage enjeksiyonuyla release akışı çalıştırılır:
   OCR metni → parser → matcher → review → onay → DB yazımı uçtan uca
   (entegrasyon testi `integration_test/receipt_flow_test.dart`).

Not: düz metin korpusu parser/matcher birim testlerini, sentetik görsel
emülatör OCR akışını doğrular; ikisi birlikte AC'yi kanıtlar.

## Dependencies

PB-036.

## Affected Areas

  receipts/**`, `integration_test/receipt_flow_test.dart`, testler.

## Acceptance Criteria

- Korpus fişlerinde: her gerçek ürün satırı ayrıştırılır; "domates"
  örneğinde plandaki ürüne öneri gelir; KDV/toplam satırları ürün
  OLMAZ; bozuk/satır kaymış fiş crash vermez.
- Yüksek güvenli öneriler review'da ön işaretli; kullanıcı onayı
  olmadan satın alma YAZIMI YOK (C-003 testle kanıtlanır).
- Emülatörde sentetik fiş görseliyle uçtan uca akış çalışır
  (integration test + gözlem).
- analyze 0 + test yeşil.
