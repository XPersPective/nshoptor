## Objective
“projeyi devral ve tümünü bitir”; PB-065 client prerequisite, ADR-007. New offers100/300 without silently replacing legacy200/1000 promises.

## Steps
1. SubscriptionService new proId/maxId are *_v2; legacy constants remain recognized in ids/tierOf/load/restore. loadOffers queries only new IDs and discards unrelated SDK results. applyOwned chooses higher tier then higher legacy allowance, independent of order. Valid credential requires recognized product/nonempty token.
2. refresh selects native _owned matching chosen product/token, not first SDK row; false/error/unknown ownership must never initiate an additional subscription. Before buy refresh when needed; cached paid ownership without a matching native record yields visible retry error rather than buy without ChangeSubscriptionParam. Existing native owner changes SKU with installed SDK replacement flow.
3. New purchase/restore event must not replace a higher tier with a lower event. Refresh full native ownership; keep current owner until full refresh result. Completion/buy/restore exceptions produce persistent generic error and retry; no raw store token/details shown. Add service/payment busy guards, clear via finally, dispose callbacks safe.
4. Paywall current legacy tier shows translated legacy-rights note; native prices unchanged, lifetime only Free AI. Change planFreeAi/ProAi/MaxAi all71 to10/100/300 with validated translations, not silent English. Add one legacy note all71. Async buy/restore disables repeat actions and remains error/retry safe. Header and period control wrap at320dp2x.
5. Tests old/new restore priority, both orderings, lifetime/free10, unknown token filtering, native matching replacement guard, delayed duplicate/failure retry, paywall legacy note and320dpRTL, all71 numeric quota consistency. No real purchase.
