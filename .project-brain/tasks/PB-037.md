# PB-037 — Şablon entegrasyonu: Pro (ömür boyu) + banner reklam + kimlik

## Status

PLANNED (PB-036 sonrası READY olur)

## Objective

ORTAK_UYGULAMA_STANDARDI §5 gelir modelini napp paketleriyle kur (C-032):
REKLAM=EVET, PRO=EVET, VERİ=YEREL.

## Somut değişiklikler

1. `pubspec.yaml`: `napp_pro` + `napp_ads` (napp_kit git etiketleri,
   `pro-v1.0.0` / `ads-v1.0.0`; güncel etiket kontrol edilir) +
   `in_app_purchase` (napp_pro gereği) + `google_mobile_ads` (napp_ads
   gereği; sürümler paketin istediği).
2. `lib/core/config/env_config.dart`: `AppIdentity` dart-define'dan
   (uygulama kimliği, mağaza kimlikleri, apps.json URL — PB-038 kullanır);
   yoksa test/güvenli varsayılanlar; uygulama sırsız derlenip çalışır.
3. `main.dart`: ProController'ı boot'a bağla (Pro durumu önce cihazdan);
   ConsentManager: UMP (AB/İngiltere) → SDK başlatma sırası.
4. `HomeShell`: bottom bar'IN ALTINDA küçük kare banner
   (`BannerAdWidget`); AdPolicy sorulur: Pro'da banner hiç başlatılmaz,
   kalkınca boşluk kalmaz. Ana sekme ekranlarının Scaffold'u buna göre
   `bottomNavigationBar` zincirine banner'ı ekler.
5. Ürün kimliği: `nshoptor_pro_lifetime` (tek, non-consumable; restore
   düğmesi paywall'da). Paywall = napp_pro `PaywallPage` (BrandLockup).
6. **Yedekleme Pro-gate** (standart §3.8): Ayarlar'daki JSON dışa/içe
   aktarma satırları `EntitlementSource` üzerinden kilitli görünür;
   Pro değilse dokununca paywall. CSV sonuç dışa aktarması serbest kalır
   (spec'in sonuç paylaşımı; standart yalnız yedek dosyasını kilitler).
7. Reklam kimlikleri: Android manifest `${admobAppId}` ← key.properties
   (`admobAppId`), yoksa Google test kimliği; birim kimlikleri dart-define,
   repoda yalnızca test kimlikleri. `key.properties.example` eklenir.
8. Ödüllü reklam → 24 saat Pro (GiftFlow) 7 gün/5 oturum korumasıyla
   (AdPolicy hazır; yalnız bağlanır).

## Dependencies

## Acceptance Criteria

- Pro değilken banner görünür (test kimliğiyle emülatör), Pro'da hiç
  görünmez + boşluk yok; AdPolicy birim testleri (paketin kendi testleri)
  + uygulama tarafı widget testleri yeşil.
- Paywall: fiyat mağazadan/varsayılan metinden, "tek ödeme — abonelik
  yok", geri yükle düğmesi; sahte indirim yok.
- Yedek dışa/içe: Pro'da çalışır, Pro değilse kilit simgesi + paywall;
  CSV serbest.
- Sırsız `flutter build apk --release` çalışır (test kimlikleri);
  analyze 0 + test yeşil; release emülatörde açılır (banner/r8 doğrulaması).
- Repoda gerçek AdMob/mağaza kimliği YOK (gitleaks + grep kanıtı).
