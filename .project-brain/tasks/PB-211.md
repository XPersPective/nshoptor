## Objective
Fix visual proportion mismatches across the home `AppBar` (oversized `?` guide and `Discover` icons vs undersized `Free`/`Pro` badge), replace the clunky cycling tab-bar sort `IconButton` with a sleek compact sort control, and standardize typography, weights, sizes, and padding across `SettingsScreen` (`Pro`, `Türkçe`, `Cihaz seçimi`, `Renk teması`, `Adet`, `TR`, switches, section headers) and shared lists UI.

## Steps
1. Refine `lib/features/subscription/plan_badge.dart` so the `Free`/`Pro` pill has balanced `32dp` visual height, `16dp` icon, consistent `labelMedium`/`w600` weight, and `>= 48dp` interactive hit box while matching the AppBar vertical centerline.
2. Standardize `lib/features/lists/lists_screen.dart` AppBar action buttons (`helpButton`, `Discover`): align icon optical size (`22dp`) inside `48x48` tap boxes and clean spacing before `PlanBadge` so `?`, `Discover`, `Free/Pro` read as one harmonious bar at `320dp–800dp` and `2x` text scale.
3. Redesign sort controls in `lib/features/lists/lists_screen.dart`: move sorting out of the squeezed `TabBar` tail into a crisp right-aligned tonal `PopupMenuButton<ListSortMode>` menu chip (mirroring `ListDetailScreen`'s `PopupMenuButton<ItemSortMode>` pattern) next to/above the list area so all tabs stay spacious and sort modes (`Date`, `A-Z`, `Manual`) are immediately legible.
4. Standardize `lib/features/settings/settings_screen.dart` typography, alignment, and padding: uniform `16dp` horizontal insets, consistent `titleMedium`/`bodyLarge` weights (`w500`/`w600`), uniform `bodyMedium` (`onSurfaceVariant`) subtitles, balanced `BrandWordmark` proportions in `settings_pro_row`, and aligned selector controls (`Language`, `Format locale`, `Theme`, `Default Unit`, `Default Currency`).
5. Add/update widget layout & overflow tests (320dp + 2x text scale, LTR + RTL, AppBar badge alignment).

## Acceptance
- [x] [visual] In `ListsScreen` AppBar, `?`, `Discover`, and `PlanBadge` share balanced proportions (`32dp` pill vs `22dp` icons) and `ListsScreen` sort selector renders as a compact labeled menu chip (`PopupMenuButton<ListSortMode>`) instead of the oversized cycling icon crammed onto the `TabBar`.
- [x] [interaction] Tapping `?`, `Discover`, `PlanBadge`, or the sort menu chip triggers its respective tour, discover page, paywall, or sort mode switch (`Date`, `A-Z`, `Manual`).
- [x] [accessibility] All AppBar actions and sort controls maintain >= 48dp touch boxes, `SettingsScreen` rows (`Pro`, `Türkçe`, `Cihaz seçimi`, `Renk teması`, `Adet`, `TR`) share uniform padding/typography with zero edge clipping or overflow in LTR/RTL at 320dp / 2x font scale, and `flutter test` passes cleanly.
