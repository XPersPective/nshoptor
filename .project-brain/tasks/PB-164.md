## Objective
Show the actual localized day or hour count in every trial countdown. ICU plural `#` currently reaches users literally, so replace it with explicit `{days}` or `{hours}` placeholders while preserving translated wording.

## Steps
1. Replace ICU `#` with explicit `{days}` or `{hours}` placeholders in both countdown messages across all 71 `lib/core/l10n/app_*.arb` files; preserve each locale's prose, plural categories, and naturally spelled singular/dual forms.
2. Regenerate `lib/core/l10n/generated/` with `flutter gen-l10n`.
3. Add a runtime localization regression test in `test/core/l10n/locales_test.dart` for all supported locales at 1, 2, and 7 days and 1, 2, and 23 hours.
