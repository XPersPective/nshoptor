# PB-045 — Premium görsel turu (alisveriş bağlamında derinleştirme)

## Status

PLANNED (PB-036..PB-038 sonrası — tüm ekranlar kesinleşince)

## Objective

Kullanıcı PB-035 sonrası bile "kesinlikle premium değil, çok kötü"
dedi (2026-10-02). Görsel dil, bir alışveriş uygulaması bağlamında
derinleştirilir; koyu tema özellikle "alışverişe uygun" olur (mağazada
göz yormayan, kontrastı koruyan). WCAG AA korunur (SemanticDelta).

## Somut değişiklikler

1. Koyu tema: gerçek derinlik katmanları (surfaceContainer hiyerarşisi
   bilinçli kullanım), kartlarda subtle ton farkı + yumuşak gölge,
   sepet/CTA vurgusu marka yeşilinin koyudaki karşılığı (0xFF0B8457
   korunur — marka kısıtı).
2. Tipografi ritmi: sayıların (tutarların) tabular-figür hizası;
   özet kartlarda hiyerarşi (planlanan vs gerçek görsel ağırlık farkı).
3. Boşluk/grafik ritmi: bölüm aralıkları 8pt grid'e oturur; liste
   satırları dokunma hedefi ≥48dp korunarak ferah tutulur.
4. Mikro-etkileşim: fiyat girildiğinde satırda küçük onay animasyonu
   (alışveriş modasında hız hissi); gereksiz animasyon EKLENMEZ.
5. Ekran geçişleri/hero: liste → detay paylaşan öğe (hero sepet ikonu
   gibi, abartısız).
6. Görsel doğrulama: emülatörde light+dark tüm ana ekranların ekran
   görüntüleri `docs/design/screenshots/` altına işlenir (PB-035
   pratiği sürer).

## Dependencies

PB-036 (akış), PB-037 (banner yerleşimi), PB-038 (5. sekme).

## Affected Areas

- `lib/core/theme/**`, tüm feature ekranları (sunum), `docs/design/**`.

## Acceptance Criteria

- Koyu temada tüm ana ekranlar kontrastlı ve göz yormayan (WCAG testleri
  yeşil + görsel gözlem).
- Tutar/sayı hizası tabular; kart hiyerarşisi kod incelemesinde
  belgelenmiş.
- Ekran görüntüleri docs/design altında; release emülatör walkthrough.
- analyze 0 + test yeşil.

## Verification

Risk: MEDIUM. Domain + görsel.

## Architecture Impact

NO (sunum).
