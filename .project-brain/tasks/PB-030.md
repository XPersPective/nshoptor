# PB-030 — Ayarlar ve gizlilik tamamlama

(Eski T30; spec §6.15, §12)

## Status

IN_PROGRESS

## Objective

Ayarlar ekranı ve gizlilik gereksinimlerini tamamla: spec §6.15'in tüm
satırları (dil, tema, varsayılan para birimi/birimler, gösterim tercihleri
güvenli alt kümesi, ekran açık tut varsayılanı, ses durumu, izin
yönlendirmeleri, yedekleme girişi, gizlilik bilgisi, hakkında — NShoptor,
sürüm, Crazy Penguin, lisanslar). Tüm verileri silme: kapsam açıklaması +
çift onay + görseller dahil tam temizlik + onay sonrası boş durum. Günlük
denetimi: fiş metni/ürün listesi/tam yol/hassas veri günlüğe yazılmıyor.

Kapanmış görev notlarından bu kapsama devreden UI bağlantıları:
- Taksonomi (mağaza/kategori/reyon) yönetim ekranına ayarlar içinden giriş (T16)
- Yedek paylaşım sayfası (share_plus) + fotoğraf dahil etme seçeneği (T21)
