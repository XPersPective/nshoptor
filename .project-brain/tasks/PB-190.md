## Objective
Device feedback F07, F08, F09 (user, 2026-10-28) — exact wording and rules in `.project-brain/references/device-feedback-2026-10-28.md`.

## Steps
1. Decouple capture from reading: photos are saved to the receipt draft immediately; after each photo offer "Photograph the rest" and "New receipt" without waiting.
2. Run AI reading in a background queue (app-level service, survives leaving the screen); persist job state in the draft so a restart resumes.
3. When a reading finishes, post a local notification; tapping it opens the owning list (and offers continuing if incomplete).
4. Reduce latency: measure per model on Evren; choose the fastest model that passes the live receipt suite; tune image size (1280–1600px).
