## Objective
Keep the settings Pro summary accurate by presenting each locale's existing no-ads, backup, and annual-plan labels instead of stale monthly billing copy.

## Steps
1. In all `lib/core/l10n/app_*.arb` files, set `proBenefitsLine` to that locale's `planNoAds`, `planBackup`, and `plansYearly`, separated by ` · `.
2. Add a focused loop in `test/core/l10n/locales_test.dart` using `lookupAppLocalizations` to confirm every supported locale's generated Pro summary includes its own no-ads, backup, and yearly labels.
3. Regenerate `lib/core/l10n/generated/` with `flutter gen-l10n`.
