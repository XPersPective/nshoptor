## Objective
Authorized Android candidate20 built AAB/APK but job40495118621 failed because its inline regex only accepts legacy Signer #1 output. New apksigner also prints scheme-specific/range signers. Preserve exact AAB certificate match; never skip signature verification.

## Steps
1. Add small stdlib helper certificate_digest(output) that reads only complete certificate SHA-256 digest lines with allowlisted APK Signer labels (legacy numbered, scheme-specific V1/V2/V3.x/V4 Signer, SDK ranges). Normalize exactly64hex or32colon-separated octets. Ignore public-key digest and explicitly Source Stamp Signer certificate (different purpose); reject unknown certificate labels/malformed digest/missing signer/conflicting unique signer digests. No guessed digest/default.
2. Replace inline regex with helper call; existing apksigner successful verification, exact AAB certificate equality, manifest/version/targetSDK and16KB zipalign gates remain unchanged. Run helper unittest before expensive build. No signing keys, identities, app code or upload changes.
3. Add bounded unit fixtures for old/new/range labels, repeated same certificate, mismatched additional signer, missing/publickey/sourceStamp-only, malformed lengths/separators/unknown label. Root independently reviews security and Bash/Python.
