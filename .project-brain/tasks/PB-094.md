## Objective
“projeyi devral ve tümünü bitir”. Import currently validates only three arrays and accepts version0/negative, malformed decimals and IDs. Imported Attachment.filePath can point outside owned media and deleteAttachment deletes it. Shared input/file trust boundaries must be guarded before PB093 native import.

## Steps
1. Trace all13 generated DTO fromJson and decimal/currency consumers. validate rejects version != BackupFormat.version, non-list optional sections, non-map rows, missing/wrong-typed DTO fields, nonpositive/duplicate IDs. Reuse generated fromJson plus existing TableInfo.validateIntegrity(...,isInserting:true).dataValid for type/length validation; use PB092 _receiptFromJson for the converted imagePaths column and force string list iteration. translate decoding/cast/argument errors to generic FormatException, do not include sensitive row contents.
2. Reuse DecimalFixed.parse for plannedQuantity/plannedUnitPrice/maxAcceptablePrice, actualQuantity/actualUnitPrice, observation quantity/normalizedBaseQuantity/unitPrice, candidate parsedQuantity/parsedUnitPrice. Validate non-null ISO via Currency.fromCode. Reuse LineCalc and checked toMinorUnits for price*quantity where present with parent list currency; reject overflow before writes. Negative purchased quantities for returns and genuine zero remain valid; no invented rounding or float conversion.
3. Check reference membership against snapshot IDs (absent nullable link is allowed, non-null missing link fails); reject cross-list plannedItem/receipt links and unknown attachment ownerType/id. Full existing valid v1 export has self-contained references; omitted optional empty tables remain accepted. Validate complete snapshot before mode confirmation.
4. AttachmentRepository.deleteAttachment must delete files only inside resolved mediaDirectory. Resolve actual file+directory symlinks, compare resolved file parent to owned flat media root before delete; outside path records may be removed but external file remains. Keep sweepOrphans directory-scoped and no source/cache/media archive redesign.
5. Add smallest regressions: bad version/type/decimal/overflow/duplicate/broken FK leaves current DB untouched; valid JPY/KWD/returns snapshots import; external temp file survives malicious imported attachment deletion while owned media file still removed. Run before/after root source and full suite/analyze. Keep substantive diff under300 lines or split before implementation.
