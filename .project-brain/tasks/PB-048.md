# PB-048 — AI vekil sunucusu (Cloudflare Worker + D1 kota + Play doğrulama)
Status: READY
Priority: P1
Tier: H
Risk: HIGH
Depends: -
Areas: `server/**`
Domains: server

## Objective
"API anahtarını … server'da gireceğim", "kesinlikle veri sızıntısı olmayacak". Uygulamanın tek AI kapısı: anahtarı saklayan, kotayı uygulayan, Pro/Max'ı Play'den doğrulayan Cloudflare Worker (ADR-004).

## Steps
1. `server/` oluştur: `package.json` (wrangler, vitest dev), `wrangler.jsonc` (name `nshoptor-api`, account `5c5871cee9d16a81a908008f2a3de9af`, `workers_dev: true`, D1 binding `DB`, vars: `AI_URL`, `AI_MODEL`, `QUOTA_FREE=15`, `QUOTA_PRO=200`, `QUOTA_MAX=1000`, `GLOBAL_DAILY=20000`, `MAX_INPUT_CHARS=6000`, `PACKAGE_NAME=com.crazypenguin.nshoptor`).
2. `server/migrations/0001_init.sql`: `usage(install_id, period, count, PK(install_id, period))`, `global_usage(day PK, count)`, `entitlement_cache(token_hash PK, tier, expires_at)`.
3. `server/src/worker.js`: `POST /v1/ai` gövdesi `{installId: 32 hex, task: parse_list|match_receipt|read_label, locale, input, purchaseToken?, productId?}`; `GET /health`; diğer yollar 404; gövde > 16 KB → 413.
4. `server/src/tasks.js`: görev başına sistem istemi + çıktı doğrulama; geçersiz çıktı → 502 `bad_model_output`. `parse_list` → `{items:[{name, quantity, unit, estimatedPrice}]}`; `match_receipt` girdi `{lines:[{i,text,total}], planned:[{id,name}]}` → `{matches:[{i, plannedId|null, confidence, isDiscount}]}`; `read_label` girdi `{text}` → `{price, unitPrice, unit, productName}`.
5. `server/src/quota.js`: aylık dönem `YYYY-MM`; tier sınırı; aşımda 429 `{error:"quota", tier, limit, used}`; global günlük tavan 503.
6. `server/src/play.js`: `purchaseToken` → SHA-256 önbellek; servis hesabı JWT (RS256, `GOOGLE_SA_JSON` secret) → `purchases.subscriptionsv2.get`; ACTIVE/IN_GRACE_PERIOD ve ürün `nshoptor_pro` → pro, `nshoptor_max` → max; hata → free (asla yükseltme yok).
7. `server/src/ai.js`: OpenAI uyumlu `chat/completions`, `response_format: json_object`, temperature 0, 20 sn zaman aşımı; anahtar `AI_KEY` secret; içerik loglanmaz.
8. `server/test/*.test.js`: kota sınırı, geçersiz installId 400, büyük gövde 413, doğrulama hatası → free, görev çıktı doğrulaması (sahte fetch).
9. Dağıtım: `wrangler d1 create nshoptor`, id'yi wrangler.jsonc'a yaz, `d1 migrations apply --remote`, secret'lar `AI_KEY`, `GOOGLE_SA_JSON`; `wrangler deploy`.
