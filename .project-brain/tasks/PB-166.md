## Objective
Provide a manually dispatched, source-pinned CI workflow that builds and verifies a signed Android candidate without uploading it to Google Play.

## Steps
1. Add a workflow-dispatch-only Android release workflow with a required exact commit SHA, read-only repository permission, bounded build settings, and a one-day candidate artifact.
2. Add a helper that validates Android signing and AdMob secrets, creates private runner-temporary signing/config files, and removes only its own temporary directory.
3. Make the existing bundle verifier select Java tool executable names portably on Windows and Linux.
