# PB-042 — Dil ↔ para birimi bağımsızlığı + çok dil altyapısı

## Status

PLANNED

## Objective

Kullanıcı 2026-10-02: "Çok dilli, çok para destekli; İngilizce konuşan
İngiltere'de oturan biri İngiliz sistemini kullanmalı; bu ayarlar
yapılabilmeli." Dil, para birimi ve biçimlendirme (locale) AYRI ayarlar
(C-001). Çok dil: ≥tr/en tam, yeni dil ekleme yolu belgeli, eksik anahtar
testi (ADR-003: ARB kalır).

## Somut değişiklikler

1. Ayarlar: "Dil" (uygulama dizgeleri) ve "Para birimi" (varsayılan liste
   para birimi — mevcut) ayrı; YENİ "Sayı/tarih biçimi" (bölge) ayarı:
   `Sistem / <locale>`; MoneySeparators ve tarih/saat biçimi bu ayarı
   izler, DİLİ DEĞİL. Öntanımlı: sistem bölgesi.
2. `MoneySeparators.forLocaleCode` çağrıları dil yerine biçim-locale'i
   okur (yeniden gözden geçir: `Localizations.localeOf` → ayrı
   FormatLocaleScope/injectable).
3. Yeni dil ekleme yolu: `docs/contributing/adding-a-language.md`
   (ARB kopyala → çevir → test otomatik yakalar); eksik anahtar testi
   iki ARB'nin anahtar kümelerinin eşitliğini doğrular (varsa
   genişletilir, yoksa yazılır).
4. RTL hazırlığı: standart §3.1 (LTR isolate sayı/birim) — napp_core
   `ltr_isolate` kullanımı değerlendirilir; tam RTL dili eklenene dek
   test şartı değil, altyapı notu olarak kalır.
5. Emülatör doğrulaması: sistem dili en + biçim tr seçiliyken "1.234,56"
   biçimi ve İngilizce dizgeler bir arada (veya tersi) — ekran görüntüsü.

## Dependencies

PB-036 (form/ayar yerleşimi stabil).

## Affected Areas

- `lib/features/settings/**`, `lib/core/money/money_format.dart` /
  `money_parser.dart` (separatör kaynağı), `lib/app/**`, l10n, testler,
  `docs/contributing/**`.

## Acceptance Criteria

- Dil en + para TRY + biçim tr kombinasyonu tutarlı çalışır (test +
  emulator gözlemi); dil değişimi para sembolünü/biçimi ZORLAMAZ.
- Yeni ARB eklendiğinde eksik anahtar testi kırmızıya düşer (bilinçli
  kısa yol testiyle kanıtlanır).
- analyze 0 + test yeşil.
