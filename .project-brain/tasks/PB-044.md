# PB-044 — Yasal/malzeme hazırlığı: gizlilik politikası + mağaza formları

## Status

PLANNED (PB-037 sonrası — reklam SDK'sı kesinleşince)

## Objective

GDPR/KVKK ve mağaza politika uyumu (standart §7; kullanıcı: "AB yasaları
vesaire önemli, yasal olarak temiz olmalı"). VERİ=YEREL olduğu için
uyum ağırlığı: reklam SDK'sının veri toplama gerçeğinin dürüstçe
yansıtılması + kullanıcı hakları (verisini dışa taşıyabilme — Pro-gated
yedek bile olsa GDPR taşıma hakkı AÇIKLAMASı gerekir; politika metninde
"verinizi istersen e-postayla talep edebilirsin/silme = uygulamayı sil"
yaklaşımı net yazılır).

## Somut çıktılar

1. `docs/store/privacy-policy.md`: herkese açık sayfaya (GitHub Pages)
   konacak TASLAK metin (tr+en): hangi veri nerede (yalnız cihaz),
   reklam SDK'sı (AdMob) cihaz kimliği/olası verileri, UMP onay akışı,
   kullanıcı hakları, iletişim. Yayınlama Crazy Penguin'e ait
   (Decision Boundary).
2. Play "Veri güvenliği" formu taslağı (`docs/store/play-data-safety.md`):
   toplanan/paylaşılan veri matrisi (reklam SDK'sı dahil), silme beyanı.
3. Yaş derecelendirme/içerik anketi taslağı (`docs/store/play-listing.md`):
   açıklama metinleri tr/en, kategori, ekran görüntüsü listesi
   (uygulamadan alınmış — vaat edilmiş özellik yok).
4. CHANGELOG sürüm disiplini: pubspec sürümü + build numarası her
   yayında artar (standart §7) — CI notu.
