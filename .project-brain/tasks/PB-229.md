# PB-229 — Consolidate duplicate app repository checkouts into canonical repositories
Status: PLANNED
Priority: P1
Tier: H
Risk: HIGH
Owner: lead
Depends: -

Inputs:
Purpose: implementation
Secrets: none
Domains: repository layout, Git remotes and branches, release changes, local project state

## Objective
Kullanıcının isteği: “Bir şeyleri yapıyorsan yerinde düzelteceksin. Projenin içerisinde güncelleyeceksin. Gereksiz olanları kaldır. En son sürümleri kendi GitHub'larına gönder ve D repository içerisindeki kopyaların hepsini sil.” Her uygulamanın kanonik D:\repositories checkout'unda gereken değişiklikleri birleştir; mevcut GitHub depolarına gönder; yalnız doğrulanmış, gereksiz sibling checkout'larını yerel kullanıcı verisini ve kanonik projeleri koruyarak kaldır.

## Steps
1. `D:\repositories` altında yakın tarihli sibling checkout'larını, origin URL'lerini, branch/commit durumlarını ve dirty dosyalarını sınıflandır.
2. Her uygulamanın kanonik checkout'unda değişiklikleri ve gerekli Project Brain notlarını birleştir; her birini kaynağa uygun biçimde doğrula.
3. Yetkili Git kimliğini kullanarak güncel dalları mevcut GitHub remote'larına gönder; gerekli PR'ları aç ve GitHub ref/PR durumlarını doğrula.
4. Her sibling checkout için temiz durum, uzak dal/PR'de korunmuş commitler, gerekli artefaktların taşınmış olması ve hedef yolun kanonik olmaması doğrulandıktan sonra kaldır.
5. `D:\repositories` son durum envanterini, korunan kanonik yolları, gönderilmiş dalları/PR'ları, kaldırılan kopyaları ve kalan engelleri kaydet.

## Acceptance
- [ ] Beş uygulamanın kanonik checkout'ları (`nshoptor`, `kamubul`, `doctorfilter`, `halen-quit-smoking`, `n-keto-tracker`) korunuyor ve içerikleri GitHub'daki güncel source değişikliklerini içeriyor.
- [ ] Her güncel source/doküman değişikliği ilgili GitHub dalında/PR'ında bulunuyor; yetim ve kayıpsız bırakılmış yerel değişiklik yok.
- [ ] Yalnız task için oluşturulmuş ve doğrulanmış redundant sibling checkout'ları kaldırıldı; özel artefakt/aktif PR taşıyan klasörler korunuyor veya gerekli verileri önce kanoniğe kopyalandı.
- [ ] Git status, branch/PR readback ve uygulamaya uygun doğrulamalar tamamlandı; sonuçlar bu görevde kaydedildi.
