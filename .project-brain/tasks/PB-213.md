## Objective
Convert receipt capture ("Fişten Listeye") and shelf label capture ("Etiket okuma") into capture-first, zero-blocking flows with Server Vision AI as primary parser (local ML Kit only as explicit offline/AI-disabled fallback). After snapping a receipt page, offer ONLY "Same receipt continue" (`Aynı fişe devam`) or "Done" (`Tamam`) so multiple receipts never mix; "Done" compresses pages to compact JPEGs, saves a unique session row (`queued`), closes capture immediately, and returns control so the user can scan the next receipt right away.

## Steps
1. Refactor `lib/features/receipts/receipt_capture_flow.dart`:
   - Preserve existing unattached queued receipts (`do not delete listId == null drafts on new capture`).
   - Compress each captured photo immediately into compact JPEG (`ai_image.dart` / `ReceiptImageStore`) without blocking UI on OCR or AI calls.
   - Show the streamlined continuation sheet after each page with ONLY two primary options: "Aynı fişe devam" (capture/pick next page into SAME session) and "Tamam" (enqueue session `queueState: 'queued'`, notify background queue scheduler, and immediately pop with snackbar/toast confirmation).
2. Update `lib/features/receipts/ai_receipt_reader.dart` and parser dispatch so Server Vision AI (`read_receipt_image`) runs directly on compressed JPEGs as the primary parser; run on-device `MlKitTextSource` ONLY when offline / AI unavailable or disabled as explicit fallback.
3. Refactor `lib/features/receipts/shelf_label/shelf_price_flow.dart` and `ai_label_reader.dart`:
   - Enforce Server Vision AI (`read_label_image`) primary with compact compressed JPEGs, ML Kit offline-only fallback, and non-blocking async option / fast fail-safe so the user can capture the next shelf item without blocking on multi-attempt ML Kit retries.
4. Add unit/widget tests for multi-page continuation (`Aynı fişe devam` -> `Tamam`), zero-wait capture exit, consecutive distinct receipt sessions, Server AI primary routing, and non-blocking shelf label flow.
