# ADR-004 — Yapay zekâ destekli revizyon: sunucu vekili, katmanlar, reklam

Status: ACCEPTED (2026-10-08, kullanıcı talebi; ADR-002'nin "sunucu yok / harici
yapay zekâ yok" maddelerini bu kapsamda değiştirir)

## Bağlam

Kullanıcı (2026-10-08): fiş ve raf etiketi okuma "indirimli elma" ile "elma"yı
kural tabanlı eşleştiremez; sesle liste oluşturma serbest cümleden yapılmalı.
Bunun için bir yapay zekâ API'si gerekir. Uygulama açık kaynak olduğundan API
anahtarı uygulamaya girmez: "ya server'da bir API anahtarı gireceğim". Gelir:
reklamlı ücretsiz sürüm + ucuz abonelik (Pro ≈ 1 $/ay + KDV) + yüksek kotalı
Max; ilk 7 gün reklamsız; az rahatsız eden açılış reklamı; ödüllü reklam 1 gün
reklamsız.

## Kararlar

1. **Sunucu vekili:** Cloudflare Worker (`server/`, hesap devx8585, workers.dev)
   + D1 kota tablosu. Uygulama yalnızca Worker'a konuşur; sağlayıcı anahtarı
   Worker secret'ıdır (repo/APK'da yok). Yayın kökündeki kaynak:
   `D:\AppPublishing\apps\nshoptor\credentials\ai\*.env`.
2. **Sağlayıcı:** OpenAI uyumlu istemci; hedef model `deepseek-flash`
   (1M girdi 0,30 $ / çıktı 1,20 $, yoğun saat). DeepSeek anahtarı yayın kökünde
   yoksa sahibin mevcut Qwen Token Plan anahtarı (`qwen3.6-flash`) kullanılır;
   anahtar eklendiğinde yalnız Worker secret/vars değişir, uygulama değişmez.
3. **Gizlilik:** Fotoğraf/ses cihazdan çıkmaz. OCR (ML Kit) ve konuşma tanıma
   (cihaz/OS) yerelde; Worker'a yalnızca metin gider (fiş satırları, plan ürün
   adları, konuşma dökümü). Worker içerik loglamaz; kota için yalnız rastgele
   kurulum kimliği + gün/ay sayacı tutar. AI kapalıyken ve çevrimdışıyken
   uygulama mevcut kural tabanlı yollarla tam çalışır.
4. **Onay:** AI çıktısı asla doğrudan yazılmaz; mevcut doğrulama ekranlarından
   (sesli önizleme, fiş inceleme, fiyat adayı) geçer (C-003 korunur).
5. **Katmanlar ve kotalar (AI işlemi / ay):** Ücretsiz 15, Pro 200, Max 1000;
   istek başına girdi ≤ 6000 karakter. Tahmini maliyet (yoğun saat, işlem başına
   ≈ 1.500 girdi + 400 çıktı token ≈ 0,001 $): Pro en kötü 0,20 $/ay, Max
   1,00 $/ay. Global günlük tavan Worker vars'ta.
6. **Fiyatlar (USD taban, Play bölge dönüşümü):** Pro 0,99 $/ay, 7,99 $/yıl;
   Max 2,99 $/ay, 24,99 $/yıl; Pro aylık planda 7 günlük ücretsiz deneme
   teklifi. Mevcut `com.crazypenguin.nshoptor.pro_lifetime` "reklamsız ömür
   boyu" olarak kalır (reklam + yedekleme; AI ücretsiz kotada), fiyatı 4,99 $.
7. **Doğrulama:** Pro/Max kotası yalnızca Worker'ın Play Developer API ile
   doğruladığı abonelik satın alma jetonuna verilir (istemci iddiası
   güvenilmez). Doğrulama kimliği Worker secret'ıdır.
8. **Reklam:** kurulumdan sonraki ilk 7 gün reklam yok; sonra banner + açılış
   reklamı (napp_ads AdPolicy: iki açılış arası ≥ 4 saat, alışveriş modunda
   yok); ödüllü reklam 24 saat reklamsız (ödüllü AdMob birimi gerekir).
9. **Çok dil:** uygulama + mağaza tr, en, de, fr, es, it, pt, ru, ar
   (ADR-003 ekleme yolu; eksik anahtar testi).
