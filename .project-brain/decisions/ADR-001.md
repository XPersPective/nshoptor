# ADR-001 — Project Brain takeover and verification baseline
Status: ACCEPTED
Date: 2026-10-18

User explicitly requested Project Brain, external CLI discovery, no Astra, and removal of Store Automation after migration.
Preserve existing Flutter/Drift/native voice/NAppKit architecture and design tokens. No replacement architecture is needed.
Use a simple period → shopping lists → item details hierarchy, with optional category/product charts; the old overview cramming limits/calendar is superseded.
Alternative: keep the dense dashboard or introduce new navigation/analytics infrastructure. Rejected: unnecessary complexity and conflicts with the requested simple hierarchy.
Brand green is an intentional semantic exception to palette accent: icon, wordmark, slogan and Pro remain stable while surfaces follow the selected theme.
Imported task claims are PLANNED until reread and freshly evidenced. Prior evidence/history is preserved in the external verified archive, never relabeled as fresh evidence.
Scope includes local store metadata readiness; upload/publishing stays outside Project Brain. Existing release readback is preserved for a separate release workflow.
