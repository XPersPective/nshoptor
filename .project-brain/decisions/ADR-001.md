# ADR-001 — Veri katmanı: drift 2.35

## Status

Accepted (2026-09-20, legacy T8)

## Context

spec §8 kalıcı katmanı için SQLite üzerinde paket seçimi gerekiyordu:
14 tablo, FK cascade/set-null, sürümlü migration, transaction rollback
gereksinimleri (C-011) ve offline-first kısıtı (C-002) altında.

## Decision

Veri katmanı drift 2.35 üzerine kuruldu. Üretilen `app_database.g.dart`
repoya commit edilir; CI'da codegen adımı yoktur.

## Rationale

drift aktif bakımda ve tip güvenli şema, sürüm migration'ları ve
transaction desteğini yerleşik verir; sqflite bunların hiçbirini hazır
sağlamaz (elle SQL + kendi migration katmanı gerekirdi).
sqlite3_flutter_libs gereksizdir: 0.6.0+ README'si "no longer does
anything" diyor — drift sqlite3'ü kendisi bağlıyor. Üretilmiş kodun repoya
commit edilmesi, CI'ın codegen toolchain'ine (build_runner) ihtiyaç
duymaması içindir.

## Alternatives

- sqflite: migration/transaction/tip güvenliği elle yazılacaktı; reddedildi.
- sqlite3_flutter_libs: no-op paket; reddedildi.

## Consequences

Şema değişikliğinde yerel `build_runner` çalıştırıp üretilmiş dosyayı
commit etmek gerekir; unutulursa CI'da analiz hatası görülür (kasıtlı
erken uyarı).
