# ADR-008 — DeepSeek-based new-offer economics
Status: ACCEPTED
Date: 2026-10-10

## Evidence and problem
User: “Dipsik’in en sonki modelinin en düşük fiyatlısına göre.” PB-087 verified official DeepSeek-V4.1-Flash pricing: peak/no-cache .30 input/1.20 output USD/M; offpeak .15/.60. Original ADR-007 cloned old .99/7.99 and2.99/24.99 USD prices. Under100/300 full typical use plus10 free users, .10USD allocated infrastructure and assumed tax20%/fee15%, old annual price fails30% contribution target; Pro is negative. See docs/audits/ai-economics.md and Decimal self-check.

## Options and choice
Keep old prices: fails the intended typical contribution target. Price only offpeak/cache: relies on unknown user timing/cache share. Set new SKU Pro1.99/month19.99/year, Max3.99/month39.99/year USD, using existing Play regional conversion: typical peak/no-cache annual contribution36.6%/40.9%. Choose this starting scenario; existing old SKU prices and200/1000 allowances unchanged. This supersedes only ADR-007 instruction to clone old new-offer prices. DeepSeek is a planning comparator; current Qwen endpoint/model/account remains by explicit user choice, not silently migrated.

## Limits
Long8192-output receipt stress remains loss-making at these prices; this is no guaranteed-profit assertion. No paid-user allowance cut or new weighted-billing scheme. Measure current Qwen credit cost and actual token mix; daily global cap is an operational ceiling, not a USD budget. New offers disclose100/300 monthly quota; annual quota remains monthly. Trial eligibility spans all app subscriptions to avoid repeated free trials across legacy/new SKUs.
