# ADR-006 — Application source and publishing ownership
Status: ACCEPTED
Date: 2026-10-26

The user requests a compact application repository, removal of obsolete Store
Automation, and one publishing home. Development uses Project Brain; releases
use Release Harbor and the existing D:/AppPublishing/README.md registry.

Keep application source, native projects, tests, localization, legal source and
nonsecret build/release automation versioned in this repository. Fastlane stays
here because it must change with the app and CI; its external credential paths
are references, not credential contents. Do not move signing material into Git.

Store metadata, screenshots, videos, credentials, release receipts and archived
QA output belong to apps/nshoptor under the registered publishing root. Runtime
test output defaults to ignored .project-brain/.cache; explicitly export valuable
evidence to the private app publishing folder. Do not delete generated locale
source or tests to reduce file count.

Canonical website source and tools will move together to apps/nshoptor/site
after application acceptance work. The tools must take the application source
root explicitly for the 71-language inventory. Preserve all existing local site
changes with hash verification before moving. Publish only validated static output
through a dedicated gh-pages artifact branch and the repository's Pages workflow;
the private publishing directory itself must never be uploaded. Keep the current
live deployment until replacement output is verified. This decision is not proof
that the site migration or deployment has happened.

Obsolete directories and root logs were archived or relocated to
apps/nshoptor/original-notes/project-cleanup-2026-10-26 with manifests, hashes and
operation receipts. History attribution backups live separately under
original-notes/history-attribution-2026-10-26. Restore by exact archived path;
never overwrite newer user work. Keep present context short and load historical
records only when needed. Website design and publication remain last.
