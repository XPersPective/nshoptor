## Objective
Kullanıcı: "geçişli reklam da olacak. Belli bir zaman her gün girdiği zaman o günlük için bir… ödüllü reklam."

## Steps
1. `lib/features/ads/ad_gate.dart`: add `static Future<bool> Function()? showInterstitial` hook; `maybeShowInterstitial()` calls it unless in grace or ad-free (policy already blocks pro).
2. `lib/main.dart`: create an app-local interstitial loader with `google_mobile_ads` `InterstitialAd.load(adUnitId: AdsConfig.interstitialUnit)`; show only if `policy.canShowInterstitial(now)`; on shown `policy.recordFullscreen(now, isAppOpen: false)`; reload after dismiss. (napp_ads `InterstitialAdManager.showIfAllowed` never calls `ad.show()`, so it is not used.) Add `google_mobile_ads` as a direct dependency with the version already resolved in `pubspec.lock`.
3. Natural stop: `list_detail_screen.dart` `_finishAndShowResult`, after the Summary route returns → `AdGate.maybeShowInterstitial()`.
4. Rewarded: enable `GiftFlow` when `kDebugMode || hasRewardedUnit` (debug uses Google test unit; release still needs the env unit), reward = 24 h temporary Pro (existing), once per day by GiftFlow/policy.
5. Test: `maybeShowInterstitial` respects grace and hook absence.
6. Root cause found on emulator: napp_ads `AdPolicyPersistence.save` writes dates as strings but `load` reads ints, and `startSession` was never saved → every launch was day 0, so app-open/interstitial/rewarded never passed the 7-day/5-session guards. Fix app-side: `AdGate.loadPolicy` accepts both; save after `startSession`, after an app-open show and after a reward. Settings tab is rebuilt on each visit so the daily gift appears once the SDK is ready.
