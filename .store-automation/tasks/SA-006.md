## Objective
Kullanıcı: "yeni bir liste dediğim zaman title kısmında mikrofon da olsun. Kişi hemen mikrofonla yazabilsin ve okeyleyebilsin." Tek alanlık dikte düğmesi: bir `TextEditingController`'a canlı (kısmi sonuçlarla) yazar; tekrar dokununca durur. İlk kullanım yeni liste başlığı; SA-007 ürün adında yeniden kullanır.

## Steps
1. Create `lib/features/voice_input/dictation_mic_button.dart` with `DictationMicButton({required TextEditingController controller, SpeechService? speechService, Key? key})`. State owns a `VoiceInputController` built lazily on first tap from `speechService ?? SttSpeechService()`; listener copies `transcript` into `controller.text` (cursor at end) while listening; disposes the controller.
2. Icon: `Icons.mic_none` idle, `Icons.stop` while `VoiceInputState.listening`; tooltip `l10n.voiceStartListening` / `l10n.voiceStopListening`; on `VoiceInputState.error` show a SnackBar with `l10n.voiceUnsupportedLanguage` (errorMessage `unsupportedLanguage`) else `l10n.voiceUnavailable`.
3. Tap while idle: `initialize()` then `start(locale: Localizations.localeOf(context).toLanguageTag())`; tap while listening: `stop()`.
4. In `lib/features/lists/lists_screen.dart` `_ListEditorSheetState.build`, set `list_title_field` decoration `suffixIcon: DictationMicButton(key: Key('list_title_mic'), controller: _title)`. Add optional `SpeechService? speechService` passthrough only if tests need it (default null).
6. Root cause of "mikrofon dinlemiyor" (found on emulator 2026-10-15): (a) device lacked the on-device tr-TR model → `unsupportedLanguage` shown only as a root SnackBar hidden behind the bottom sheet; (b) native `startSpeech` destroyed the just-created recognizer → `recognition_11` (server disconnected). Fix: `SpeechService.requestLanguageModel` + native `downloadModel` (API33 `triggerModelDownload`, no re-prompt while pending) with message key `voiceModelDownloading` (71 ARB via `tool/i18n/add_keys_local.py`); error text on the mic tooltip (`voiceErrorText`); reuse the unused recognizer; no-speech codes 6/7 return to idle.
5. Add `test/features/voice_input/dictation_mic_button_test.dart` using `FakeSpeechService`: tap → listening icon; `emitPartial('elma')` → field text `elma`; `emitFinal('elma armut')` → `elma armut` and idle icon; unavailable service → SnackBar text `voiceUnavailable`.
