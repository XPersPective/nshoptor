## Objective
Kullanıcı: "aşağıdaki o input kısmına tıkladığı zaman edit menüsü açılmalı. Onun içerisindeki mikrofona tıklarsa da toplu halde giriş yapabilmeli… konuşurken de mikrofon dinliyor olabilmeli. Ve oradaki örnek olan cheese, 1 kilogram apples gibi olan yere kişinin konuştukları anlık olarak yazılıyor olabilmeli. Turn into a list dediği zaman da onu düzgün bir şekilde ayrıştırıp hem kategorisini hem de şeyini otomatik girebilmeli."

## Steps
1. `list_detail_screen.dart` composer `detail_quick_entry`: `readOnly: true`, `onTap: () => _openItemForm(context)` (new item form from SA-007). Remove `onSubmitted` and `_quickEntry`; hint `l10n.itemFormTitle` ("Ürün ekle").
2. Composer mic `detail_quick_list`: `_openQuickList(context, autoListen: true)`; in `_openQuickList` pass `showMic: true` so the sheet shows a stop/restart mic.
3. `list_draft_sheet.dart`: while listening, the text field shows the live transcript (already copied in `_onVoice`) and a visible listening indicator: `LinearProgressIndicator` above the field with key `draft_listening`. When listening ends with non-empty text and no draft, keep text and enable `draft_convert_button`. A new listening session appends to the existing text (`_prefix`).
4. Fix: `_listen()` must not require `_micBusy` to be false when called from autoListen; ensure `autoListen` path calls `initialize()` then `start()` once; on error show existing `draft_voice_unavailable` text.
5. (Done in SA-006: missing tr model + recognizer error 11.) Verify on the Android emulator why the mic "does not listen": capture `adb logcat` for the native speech channel while tapping the mic; if the cause is in Dart, fix it here; if the device lacks an on-device recognizer, the sheet must show `voiceUnavailable` instead of silently idling (add Step to Notes with the logcat line).
6. Tests: composer tap opens ItemFormSheet (`item_name_field` visible); mic opens draft sheet in listening state with FakeSpeechService, `emitPartial('1 kg elma')` shows in `draft_text_field`, `emitFinal` enables convert.
