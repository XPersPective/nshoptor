## Objective
Kullanıcı: "üyeliğin 7 günlük deneme sürümü olacak… yukarıda mevcut planların, pro, max gibi… simgesi olacak. Yani şu anda ne kullanıyor? … uygun bir büyüklükte pro, max veya ücretsiz ya da deneme sürümü olduğu olacak."

## Steps
1. `subscription_service.dart`: in `buy(offer)`, when `offer.hasTrial`, store `sub_trial_until` = now + 7 days (ms) in `store`; getter `bool get inTrial` = tier != free && now < trial_until; clear key when ownership becomes free.
2. `settings_screen.dart` AppBar actions (before giftFlow): `ActionChip(key: Key('settings_plan_badge'), avatar: Icon(Icons.workspace_premium, size: 18), label: Text(label))` where label = `Max` / `Pro` / `Pro · ${l10n.planTrial}` when inTrial / `l10n.planFree`; lifetime/temporary pro (`_proUnlocked` without subscription) → `Pro`. Tap → `_openPlans` (or paywall when subscriptions null).
3. Move the "NShoptor Pro" section to the top of the settings ListView.
4. Tests: badge text for free/pro/trial using a fake store.
