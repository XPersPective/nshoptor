## Objective
Kullanıcı: "edit yazısı olmayacak. Item name kısmının yan tarafında bir tane mikrofon olabilir." · "Ayrıntılarda gerçek miktar falan filana gerek yok… İndirimi geç… daha fazla kabul edilir fiyat isteği bunu kaldır. Burası biraz sade olması lazım. Marka olur, kategori olur… ve not olabilir." · "Satır toplamıyla birim fiyatı anlamadım." · "Kategoriyi istiyorsa kendi doldurur, isterse yapay zeka kategorize edebilir."
Form tek ve sade: Ad (+mikrofon), Miktar+Birim, Evdeki Fiyat (birim başına), Çarşıdaki Fiyat (birim başına, isteğe bağlı); Ayrıntılar içinde yalnız Marka, Kategori, Not. Kategori boşsa ürün hafızasından otomatik.

## Steps
1. `item_form_sheet.dart` build: delete the header Row (title `itemFormTitle/editAction` and `item_voice_button`); delete `onVoicePressed` param and `_onVoicePressed`.
2. `item_name_field` decoration: `suffixIcon: DictationMicButton(key: Key('item_name_mic'), controller: _name)` (SA-006).
3. Field order: name, Row(quantity, unit), `item_price_field`, `item_actual_price_field`. Price labels: `l10n.compareEstimated` / `l10n.compareActual`, both with `suffixText: '/ ${unitDisplayName(_unit, l10n)}'`; actual keeps `helperText: l10n.priceOptionalHint`. Remove the `_otherSidePreview` text and method.
4. Planned price is always unit price: delete `item_pricing_mode` SegmentedButton; `_priceIsUnitPrice` stays true for save. Prefill for an existing item: `item.plannedUnitPrice ?? ''` (repository already stores unit price for line-total items).
5. Actual price is always unit price: delete actual quantity field, actual unit dropdown, actual pricing-mode dropdown, discount field from Details. Prefill when entries exist and not `_mixedUnits`: single entry with `actualUnitPrice` → that; otherwise sum(gross = actualLineTotal + discount) / sum(actualQuantity) at `DecimalFixed.maxFractionDigits`, empty if no known price (existing rule `grossTotalMinorUnits == null && source != 'receiptOcr'`).
6. Save: when `_actualChanged`, `recordPurchase(quantity: planned quantity, unitCode: _unit.dbCode, unitPrice: actualPrice, lineTotalMinor: null, discountMinor: existing summed discount)`. Mark `_actualChanged = true` also on quantity/unit change when entries exist and actual price text is non-empty.
7. Details keeps: brand, category (`item_candidate_category` free text when `_categoryName != null` + dropdown), note. Delete max price field and `item_required_toggle` from UI; existing `maxAcceptablePrice`/`requiredFlag` values are passed back unchanged on save.
8. `item_repository.dart` `addItem`: when `categoryId == null` and `categoryName` blank, set `categoryId = await CategorySuggester(_db).suggestCategory(normalizeName(name))`.
9. Update tests that used deleted keys (`item_actual_quantity_field`, `item_discount_field`, `item_pricing_mode`, `item_actual_pricing_mode_*`, `item_required_toggle`, `item_voice_button`) to the new form; keep their data assertions where the field still exists. Add a test: existing item with entry 2 kg @ 10 → form shows actual 10; edit actual to 12 → entry unit price 12, quantity 2.
10. Add a repository test: item without category whose product memory has defaultCategoryId gets that category.
